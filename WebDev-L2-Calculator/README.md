# Oasis Infobyte - Web Development & Designing Internship

## Level 2 - Task 1: Calculator

### Description
A fully functional browser-based calculator built using vanilla JavaScript, HTML5, and CSS3. It supports standard arithmetic operations, operator chaining, clear/backspace functions, and error handling for division by zero.

### Tech Stack
- **HTML5**: Structure and layout
- **CSS3**: Styling and responsive CSS Grid button layout
- **JavaScript (Vanilla)**: Calculator logic, state management, and event handling

### Features
- Numeric buttons (0-9) and decimal point
- Arithmetic operators (+, -, ×, ÷)
- Operator chaining for sequential calculations
- Clear (C) and Backspace/Delete functionality
- Prevention and error message handling for division by zero

### How to Run
1. Clone or download the repository.
2. Open the `index.html` file inside the `WebDev-L2-Calculator` folder directly in any web browser.
