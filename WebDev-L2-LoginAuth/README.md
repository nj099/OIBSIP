# Login Authentication system using react and nodejs

A client-side authentication system built for managing user registration, login validation, and a protected dashboard view.

### How It Works
- **Registration:** Users can sign up with password validation checks (ensuring it's secure with numbers and minimum length).
- **Login & Sessions:** Validates credentials and handles redirection. If you aren't logged in, the app blocks you from viewing the dashboard.
- **Data Handling:** Uses browser storage to safely keep track of registered accounts locally.

### Tech Stack
- React / NodeJS / Express.

### How to Run
Follow the local server instructions or open the frontend build files to test out the login flow.
