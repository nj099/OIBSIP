# To-Do Web App

This is a clean, interactive To-Do list application I built to help manage daily tasks efficiently. 

### Features Included
- **Add Tasks:** Type a task and hit add to push it straight into the pending list.
- **Edit & Delete:** Easily toggle tasks between pending and completed states, or delete them when done.
- **Live Counters:** Keeps track of how many items are pending vs. completed.
- **LocalStorage:** Added this so that your tasks don't vanish if you accidentally refresh the page (took me a little trial and error to get the JSON parsing right!).
- **checkbox:**to check that the task is completed.

### Tech Stack
- HTML5, CSS3, and Vanilla JavaScript (DOM manipulation).

### How to Run
Open `index.html` in your browser and start adding tasks!
