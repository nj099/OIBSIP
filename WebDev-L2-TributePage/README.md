# Tribute Page 

This is my Tribute Page project for the Oasis Infobyte internship. I decided to build this page to honor Mr. Narinder Singh Kapany.

### What I Used
- **HTML5** for the core structure and text layout.
- **CSS3** for styling, custom fonts, and making sure it looks neat on mobile screens too.

### How I Built It
I wanted to keep the design clean and respectful. I used a two-tone background style across sections to keep it visually engaging, added an image sourced from Wikimedia, and structured a timeline of key milestones using CSS flexbox. 

### How to Run
Just download or clone the repo and open `index.html` in any browser!
